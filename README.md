# ALU Data Extraction & Secure Validation Assignment

This project uses Python and Regular Expressions to extract structured data (emails, phone numbers, credit cards, URLs, times, and amounts) from raw text and save it to JSON format.

## Folder Structure

```text
alu-regex-data-extraction_K-Nixon-0/
├── input/
│   └── raw-text.txt
├── src/
│   └── main.py
├── output/
│   └── sample-output.json
└── README.md

```
